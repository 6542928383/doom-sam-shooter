# DOOM · SAM — Hybrid FPS

A first-person shooter that fuses **classic DOOM-style fast combat** with **Serious Sam-style horde arenas**, built as a TypeScript + three.js web game.

> 🚧 This repository is being built up iteratively as a series of pull requests. See open PRs for the latest work.

## Status

This is the empty scaffold. The actual game arrives via a series of feature PRs:

- **PR #1 — Foundation:** TypeScript + three.js + Vite project, FPS controller, basic arena, hitscan pistol, melee enemies, HUD, death/respawn flow.
- **PR #2 — Arsenal:** Full 7-weapon arsenal (fist, pistol, shotgun, chaingun, rocket launcher, minigun, cannon), inventory, projectile system.
- **PR #3 — Bestiary:** ranged imps, kamikaze rushers, heavy bulls, flying skulls, spawn waves.
- **PR #4 — Levels:** 3+ hand-built levels with corridor/arena flow.
- **PR #5 — Pickups & damage model:** medkits, armor, ammo crates.
- **PR #6 — Audio:** SFX and looping soundtrack.
- **PR #7 — Menu & flow:** main menu, pause, settings, win/lose screens.
- **PR #8 — Polish:** balance, boss encounters, additional arenas.
